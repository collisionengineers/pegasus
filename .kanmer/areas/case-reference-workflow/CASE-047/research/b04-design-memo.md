## 2. Target formula and operation mapping

Plan formula (verbatim, B04): `P = Σ Replace qty × unit price; L = eligible panel hours × one rate; Q = Paint/Blend paint hours × the same rate; M = row materials + Additional materials; S = Specialist fixed qty × unit price + Other costs; O = off-pattern unit amounts in specialist treatment; Category = P(1−dP) + L + Q + M(1−dM) + (S+O)(1−dS); Net = Category(1−dA); Taxable = selected discounted categories(1−dA); VAT = Taxable × 0.20; Gross = Net + VAT`. Printed: each discounted category and VAT rounded independently to 2 dp away from zero — Parts `P(1−dP)(1−dA)`, panel labour `L(1−dA)`, paint labour `Q(1−dA)`, Materials `M(1−dM)(1−dA)`, Specialist `(S+O)(1−dS)(1−dA)`, VAT from the unrounded selected taxable base; printed Net = Σ printed components; printed Gross = printed Net + printed VAT; never move a residual penny. Specialist hours displayed, never multiplied. Zero/missing fixed-cost qty = 1. Discounts validated in [0,1].

Operation → persisted `Type` (decided):

| Operation | Default Type | Also read back as | Bucket |
| --- | --- | --- | --- |
| Replace | `new_part` | — | P (qty × unit); its panel hours → L |
| Repair | `repair` | — | L |
| RemoveAndRefit (R&I) | `rnr` | — | L |
| Paint | `paint_repair` | `paint_new`, `paint_prep` | Q |
| Blend | `paint_blend` | — | Q |
| Specialist | `specialist_fixed` | `specialist_wu` | S (max(qty,1) × unit); hours displayed only |
| Other | `check_labour` | — | panel hours → L; any unit amount → O |

Type is rewritten only when the operator changes the operation (an imported `paint_prep` row stays `paint_prep`). `Other → check_labour` closes the round trip (`EstimateTests.cs:58`). No new type strings, so no `CK_CaseEstimateLines_LineType` change. Open point: existing `specialist_fixed` rows display as Other today and Specialist after; production data is disposable (D10), record in the plan. L = Σ WorkUnits over non-Specialist rows; Q = Σ PaintWorkUnits over Paint/Blend rows only; paint hours or unit amounts on other rows are off-pattern: retained, flagged, O discounted by dS.

Row fields: operation (derived), description, part number, quantity (0/missing → 1 in calculator), panel hours, paint hours, materials (new decimal), fixed unit amount (reuse `Price`), origin/current values (F: `OriginalValuesJson`/`CurrentValuesJson`), source doc id/version/hash + row identity (F columns), amendment actor/time (F columns), off-pattern flags (carry in `CurrentValuesJson`). Estimate level: Additional materials (`PaintMaterials`), `OtherCosts`, discounts dP/dM/dS/dA, VAT flags, `RepairerVatStatus ∈ {Unknown, Registered, NotRegistered}`, override state (`VatOverrideReason` non-null ⇒ overridden), rate snapshot (`LabourRate` + `RateCardId`/`RateCardVersion` when a card exists), calculation policy version + raw/printed breakdown (`CalculationBreakdownJson`). Defaults: Registered → all four; NotRegistered → Parts + Materials; Unknown → blocks Use-as-Current until explicit status or explicit categories. Claimant VAT never controls estimate VAT.

Governing-doc conflicts to raise (docs are A-owned; B records them in the PR and here): (1) FRD-11 "estimate VAT on the rendered report" and design README `:1063-1066` say the rate card prices non-paint labour only (D17) while the plan applies one rate to paint hours; (2) plan hard-codes 0.20 while D9 makes VAT % free per estimate — recommendation: keep `VatPercent` (default 20) and compute VAT = Taxable × VatPercent/100; (3) design README `:1051-1052, 1167-1168, 1227-1229, 1249` say Glass's launch controls are absent (D21) and there is no Import control — D03/the plan add both; A08 docs must record the superseding decision.

## 7. Session policy over A's published contract

States (A): Prepared → Launching (start-ere in flight; an unknown outcome here → Unknown, never auto-replace) → Active (estimator URL handed over, awaiting callback) → Completed (callback validated + relayed + XML/PDF validated and retained through `ICaseArtifactCustody`) → Importing (canonical import pending; used for the stale-lease/version case: retain artifacts, require the engineer to regain edit authority, `OnPostResumeGlassAsync` replays only the import) → Completed-with-import (record `ImportedEstimateId` in `ResultArtifactsJson`); Failed (attributable), Unknown (uncertain external side effect; human reconciliation), Expired (`ExpiresAtUtc` passed or `CredentialGeneration` ≠ current enabled generation), Cancelled. Normalized account key: trim, lower-invariant, NFKC, then hex SHA-256 with a fixed application salt; password never contributes; `ActiveAccountKey` = key while state ∈ {Prepared, Launching, Active} else null (filtered unique index gives one active session per external account across users and generations). Idempotency: `OperationKey` unique; identical callback replay → recorded result; different raw query → conflict, nothing changes (`CallbackDigest` + `CallbackConsumedAtUtc`). Every gateway result carries Succeeded | Failed | Unknown as data, not exceptions.
