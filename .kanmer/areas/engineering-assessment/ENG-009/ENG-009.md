## Why

Give staff a case-centred action to request a Cazana valuation through the application backend.

## Scope

- Add the case-workbench UI action that initiates a Cazana valuation.
- Do not expose VRM, mileage, or date inputs: obtain all three from the case.
- Use the case incident date as the valuation date.
- The UI must call the application path, never Cazana directly.

## Verification

- The action initiates the backend valuation request for the selected case.
- The screen contains no editable VRM, mileage, or valuation-date option for this action.
- Coverage proves the valuation request uses the incident date rather than today’s date.

## Notes

- Depends on the backend Cazana valuation path.
- Governing requirements remain to be created.
