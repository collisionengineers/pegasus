## What

Remove the permanently inert `Open in Glass's` and `Audatex` direct estimating-service controls from the Assessment record bar.

## Why

The operator confirmed on 2026-09-01 that direct Glass's/Audatex service-launch controls remain excluded. The supplied PDFs authorize file import research only; they do not establish vendor API access, licensing or a real destination. TICK-085 owns Glass's file import, not a direct link.

EPIC-011 D21 requires an unavailable capability to be absent rather than drawn as a disabled control. Both buttons currently have hard-coded unavailable conditions and no reachable enabled state.

## Approach

- Remove both controls and their hard-coded condition properties from `Pages/Cases/Assessment/Index.cshtml(.cs)`.
- Preserve Audatex/Glass's file import through [[ENG-002]], [[ENG-032]] and [[TICK-085]].
- Coordinate the shared Assessment files with [[ENG-028]].
- Do not introduce a closed feature flag, placeholder route, external API client or licensing work.
- Record the settled exclusion in the EPIC-011 decision/context record.

## Verification

- [ ] Neither direct-service control is rendered in any state.
- [ ] No hard-coded direct-service condition property remains.
- [ ] Audatex and Glass's file import controls remain mapped to their real parser owners.
- [ ] [[ENG-025]] has no permanently inert estimating-service control left to discharge.
