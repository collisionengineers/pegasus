## What

Make Export the single current send-to-Engineer action. Staff export a reviewed Case and import the package into EVA. Every successful export records permanent action history; the first also records the once-per-Case `First sent to Engineer` proxy.

## Business rule

`Review` is the one readiness owner. It requires complete instructions and images. Export checks Review server-side and does not duplicate Case custody, Audit custody, field-status or accepted-only evidence rules.

Suggested populated values are usable. VAT and Mileage are optional. Mileage requires Unit when present. Blank Inspection Date defaults to the date Export is pressed.

## Routes

1. Current: manual EVA package import.
2. Later: EVA API when usable.
3. Later: direct estimating integrations replacing EVA.

AI-generated estimates may remain in Pegasus for Engineer review/report generation.

## Scope

The duplicate hand-off UI, routes, MCP tools, Core ports and persistence tables are removed. The surviving POST uses antiforgery, an exact-replay operation key, action history, the first-export proxy and `Content-Digest`.

The direct schema-removal migration is intentional pre-release work under ADR-0030. No rollback or compatibility machinery is required.

## Evidence

Commit `cf28b8b0`; PR #539. Locked restore and Release build passed. Full non-corpus tests: Core 975, Architecture 99, Integration 945 with two declared skips. Independent review and final CI remain required.
