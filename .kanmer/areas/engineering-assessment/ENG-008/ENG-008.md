## Why

Add the backend path for an operator-initiated Cazana market valuation without extending the integration beyond valuation.

## Scope

- Call only Cazana `GET /valuation/1.0`.
- Take the VRM, mileage, and valuation date from the case; the valuation date is the case incident date.
- Send no VIN and do not request condition, confidence, stocking-depreciation, or other Cazana API data.
- Define the worker/function contract, credentials/configuration boundary, result handling, and failure behaviour before activation.

## Verification

- Automated coverage proves the request contains the case VRM, mileage, and incident date.
- Automated coverage proves no other Cazana endpoint or optional valuation feature is called.
- A caller can receive the valuation result or a defined failure outcome.

## Notes

- API evidence: `reference/cazana-api-spec.json` (`GET /valuation/1.0`).
- Governing requirements remain to be created; direct provider access requires the separate commercial and live-operation approval evidence.
