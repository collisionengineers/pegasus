## What

Accept one raw estimate artifact dropped anywhere on the Assessment page and import it immediately, with no confirmation and no visible picker, through one shared Core import command (Case id, expected version, edit lease, operation key, filename, media type, bytes, channel). The same command serves the MCP raw-artifact caller.

## Why

Operator decision D16 (2026-09-01, EPIC-011 `decisions/2026-09-01-work-pack.md`): drag-and-drop of an estimate is the intended route. Today the Assessment page imports through a dialog with a 10 MiB dropzone ([[ENG-002]], [[ENG-028]]) and no shared Core command exists.

## Approach

- Extract the shared Core command from the existing `OnPostImportEstimateAsync` path in `Pages/Cases/Assessment/Index.cshtml.cs`; reuse `IEstimateDocumentParser` routing; accept only currently registered parser types; auto-detect provider/parser and fail closed on ambiguity.
- Name Drafts by provider plus sequence; record filename, hash, provider/parser, actor, channel and outcome. Same Case plus same hash is an idempotent replay; a different artifact creates the next immutable Draft.
- Remove the Import estimate dialog and picker. The pointer-only drop exception is recorded narrowly in FRD-12 acceptance evidence by the governing-docs chore.
- Files: `Pages/Cases/Assessment/Index.cshtml(.cs)`, `wwwroot/js/site.js` dropzone, `src/Pegasus.Core/Assessment/EstimateImport.cs` (assessment_shared and global_shell locks; coordinate with [[ENG-030]], [[ENG-032]], [[TICK-085]]).

## Verification

- [ ] One file dropped anywhere on the page imports immediately; unsupported types are refused before upload.
- [ ] Same Case plus same hash replays the existing Draft; a different artifact creates the next Draft.
- [ ] The three Audatex and four embedded-text Glass's oracles pass through this caller (YL69YFO through TICK-085's recorded fixture).
- [ ] Browser lane covers keyboard reachability of the resulting Drafts; the pointer-only exception is recorded.
