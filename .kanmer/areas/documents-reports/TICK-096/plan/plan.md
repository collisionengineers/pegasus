## Risks / open questions

- **Premature capability claim:** SIMPLI-014 proves the adapter, not accepted production data/caller. Mitigation: two-stage acceptance and explicit blockers; do not close after the adapter merge alone.
- **Cross-ticket overlap:** every plausible RPT-01 implementation file belongs to SIMPLI-014 or DOCS-001/upstream data tickets. Mitigation: no independent worktree/diff; return gaps to the owning ticket.
- **Second calculation owner:** migrated renderer models may retain settlement/fee calculations. Mitigation: source and test proof that Core supplies one accepted value set and Infrastructure only validates/formats.
- **False determinism claim:** PDF bytes may vary across browser/font/OS environments. Mitigation: pin and record the production environment, prove repeatability/structural parity within it, store the actual hash, and avoid cross-environment byte-equality claims.
- **Visual-only confidence:** a plausible PDF can still use stale/unaccepted data. Mitigation: pair representative artifacts with typed readiness/source-version/calculation tests and immutable result provenance.
- **No operator question:** initial assessment/fee-note scope is resolved; Audit and inactive catalogue families remain deferred.
