## Why

PR #539 replaces the established batch content-read path with serial `OpenReadVersionAsync` calls per image. With Box storage this repeats traversal and serializes downloads.

## Required outcome

Reuse `ReadVersionsAsync` for the export image set unless a measured current requirement proves a different shape is necessary.

## Verification

A test proves one batch read serves the export while preserving exact document/version/hash validation and deterministic image order.

## Outcome

Resolved in PR #539 at commit c86b803c. Focused evidence is recorded in the post-implementation report.

No real operator Export/EVA import was performed, so that end-to-end handoff is not claimed.
