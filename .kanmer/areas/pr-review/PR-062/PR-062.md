## What
Correct ADR-0032 and ADR-0002 frontmatter so a clause-level partial supersession is not represented as whole-ADR supersession.

## Why
PR #547 keeps ADR-0002 accepted and states that only polling/timer-first intake triggering is replaced, but sets `ADR-0032.supersedes: [ADR-0002]` and `ADR-0002.superseded_by: [ADR-0032]`. Those fields describe the whole ADR and conflict with the stated partial scope. ADR-0030 is the repository precedent for a partial clause replacement: it leaves whole-ADR relationship fields empty and records the limited scope in the status/body.

## Acceptance
- ADR-0032 and ADR-0002 machine-readable frontmatter no longer imply whole-ADR supersession.
- The status/body and ADR index still identify the polling/timer-first clauses as partially superseded by ADR-0032.
- Documentation link checks and `git diff --check` pass.

## Outcome
PR #549 merged the two-line metadata correction into the INTK-041 review branch at 800cdc7c. Documentation links and applicable CI passed; no runtime or cloud state changed.
