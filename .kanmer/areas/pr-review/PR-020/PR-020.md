## What

Treat provider timeouts as Deleted Items unavailable while preserving genuine caller cancellation.

## Why

`GraphDeletedMailSearchSource` catches provider HTTP/access/throttle failures but not `TaskCanceledException` produced by `HttpClient.Timeout`. A provider timeout therefore escapes to a 500 instead of the explicit unavailable state. This blocks [[TICK-053]].

## Verification

- Test a transport timeout with a non-cancelled request token and assert unavailable.
- Test genuine caller cancellation still propagates.
