## What

Include the active retained-mail search predicate when deciding whether a thread message remains inside the originating list scope.

## Why

PR #469 preserves the search term on every thread link, but `MessageModel.ReloadAsync` checks only mailbox and folder. A nonmatching conversation member is therefore shown without the required no-longer-in-this-view state, and Back returns to a filtered list that cannot contain it. This blocks [[TICK-053]].

## Verification

- Exercise an authenticated retained search, open a matching message, then navigate to a nonmatching member of the same retained thread.
- Prove the search remains preserved and the detail renders the explicit outside-view state.
