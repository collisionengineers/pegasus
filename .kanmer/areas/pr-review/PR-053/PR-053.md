## Why

PR #491 adds `Current view: …` as `field-hint` and a queue-specific empty-state paragraph to the read-only Inbox. The repository design rule permits labels and values but forbids field hints, explanatory copy, and empty-state panels on read-only views. The native selected option already exposes the active value.

## Required outcome

Remove the new explanatory field hint and queue-specific empty-state panel. Preserve one labelled native selector, its selected value, and the existing compact list state without adding replacement guidance or another component.

## Verification

- [ ] The selected queue/detail value remains programmatically and visibly exposed by the native selector.
