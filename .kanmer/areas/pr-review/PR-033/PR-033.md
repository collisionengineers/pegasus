## What

Map successful-but-malformed or scope-invalid Deleted Items Graph responses to the existing unavailable state.

## Why

At PR #469 head `7932d683`, Graph JSON/shape/folder/next-link validation can throw `JsonException`, `InvalidDataException`, or `UnauthorizedAccessException`. `GraphDeletedMailSearchSource` does not catch these external response failures, so authenticated `/Inbox` returns 500 instead of failing closed as unavailable. This blocks [[TICK-053]].

## Verification

- Prove malformed JSON, missing required identities/time, foreign parent folder, and escaped next link yield `DeletedMailSearchState.Unavailable`.
- Preserve caller cancellation and add no retry or exception framework.
