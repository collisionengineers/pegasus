## Why

`CaseCompletenessPolicy` still permits administrator configuration to waive instruction/image completeness, and `EfCaseDataStore` promotes to Review from that result. That contradicts the new mandatory Review rule and can allow an incomplete case to export.

## Required outcome

Remove or constrain the obsolete waiver path so every creation, transition and return to Review requires complete instructions and images.

## Verification

Tests cover every configuration combination and prove incomplete evidence never reaches Review.
