## Why

FRD-08 requires a successfully moved message to leave Inbox and remain findable through its destination-folder scope or search. PR #477 only adds an Inbox `NOT EXISTS` filter. The current workspace exposes Inbox, Sent, and Deleted scopes, so the moved item disappears from all list/search entry points and is reachable only by a retained direct URL.

## Verify

- Overlay the latest successful logical/current folder into the canonical retained-mail query owner.
- Provide the smallest existing-convention destination-folder or search route that can return the moved message without duplicating it.
- Prove Inbox exclusion, destination/search inclusion, paging, mailbox scoping, and immutable arrival evidence.
- Do not create a second search store or folder taxonomy.
