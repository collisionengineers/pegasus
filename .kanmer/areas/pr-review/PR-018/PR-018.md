## What

Associate search projections and searchability with the exact retained attachment, not filename alone.

## Why

PR #469 converts searchable projection rows into a case-insensitive filename set. Two attachments with the same filename, where only one is readable, are both shown as searchable; matching evidence can likewise name the wrong occurrence. FRD-08 requires honest per-attachment unsupported/searchable disclosure. This blocks [[TICK-053]].

## Verification

- Cover duplicate filenames with different readable/unreadable outcomes.
- Reuse existing attachment ordinal/source identity and retain one projection/store.
