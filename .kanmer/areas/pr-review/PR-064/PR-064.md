## What

Correct the remaining semantic-fidelity contradictions in PR #557's Test UI catalogue and make the validator reject an image-bearing prototype whose image has no source.

## Why

[[PR-063]] claims all 39 visual defaults map to the rendered Razor/PageModel branch they name, but two reviewed mappings disprove that claim:

- `administration-organization-edit--default.html` is inventoried as "Loaded organization with no principals or roles" while it renders principal `WEBP` and a checked Work Provider role.
- `vehicle-images-details--default.html` is inventoried as an image-bearing branch but its gallery image is `<img ... alt="vehicle-front.jpg">` with no `src`. The current validator reports zero broken references because it does not reject the missing source.

## Approach

- Choose one valid organization-edit branch and make the inventory claim and static markup agree with the current Razor conditional branches.
- Give the image-bearing state a tracked evidence-safe image source already present in the repository, or select and accurately document the no-images branch.
- Extend the existing catalogue validator only as needed to reject a visual image element with an absent or empty source.
- Correct [[PR-063]] and [[UIIMP-002]] evidence claims after rerunning the checks.
