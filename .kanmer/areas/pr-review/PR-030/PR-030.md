## What

Ensure a Deleted Items MIME read still belongs to the exact resolved Deleted Items folder before returning it.

## Why

PR #469 lists folder-scoped immutable IDs, then reads MIME through the mailbox-global message route. If a message moves between those operations, Pegasus can return content that is no longer in Deleted Items, violating the exact mailbox/folder scope. This blocks [[TICK-053]].

## Verification

- Simulate a message moving after folder enumeration and before MIME retrieval.
- Prove moved content is withheld or the request becomes honestly unavailable, while an unchanged item remains readable.
- Preserve GET-only access and the global scan/MIME bounds.
