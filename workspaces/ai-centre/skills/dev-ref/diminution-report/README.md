# diminution-report

Drafts and reviews **claimant-side** diminution-in-value reports, solicitor advice notes, and post-repair market-stigma assessments for Collision Engineers. This is CE's own opinion — distinct from `diminution-rebuttal`, which attacks a third-party formula report.

## What it provides

- **`SKILL.md`** — output modes (full expert report, advice note, stigma review) and the workflow.
- **`references/`** — diminution methodology and drafting guidance.

## Uses

`vehicle-valuation` (whenever the conclusion depends on pre-incident value, post-repair value, comparables, or live advert support), plus `collision-engineers-design` and `ce-house-style` for report layout and voice.

## Status

Dev-holding — kept out of normal dist builds pending completion (see `dev-docs/repo/DISTRIBUTION-READINESS.md`).

## Layout

`README.md` and `AGENTS.md` live in this `-dev` wrapper (never uploaded); the uploadable skill is the nested `diminution-report/` folder. See `AGENTS.md` for maintenance notes.
