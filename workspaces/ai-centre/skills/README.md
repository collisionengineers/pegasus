# Production skills

Reusable, typed business capabilities invoked by workstation agents live here: evidence extraction,
case matching, assessment checks, vehicle lookup, cited retrieval, correspondence drafting, report
assembly, and quality control.

This folder is not `.agents/skills/`. The latter configures coding/contributor agents; this folder is
runtime product code. Each skill needs a narrow contract, permission/data classification, deterministic
test double, audit behaviour, timeouts/retries, and scenario tests.
