# Query Response Boundaries

> **Source-workspace boundary:** This file is package-local evidence or an experiment only; it is not a Pegasus caller, policy, current instruction, or acceptance authority. `Pegasus.Core`, current operator authority, and an authorised human own every accepted fact, category, outcome, external response, and approval.


Use this before drafting external category dispute wording.

## Safe response structure

1. Identify the evidence reviewed.
2. Separate repair economics from category reasoning.
3. State the structural/non-structural or special-case basis.
4. Address salvage value/rate only after checking vehicle value, repair costs, category, and any
   open-market salvage evidence.
5. Identify missing evidence if the category or salvage rate is provisional.
6. Invite specific contrary evidence rather than debating assertion.

## Salvage rate challenges

Use where a TPI relies on its own contracted salvage arrangements:

- Do not accept a contracted insurer salvage rate as the claimant's open-market salvage position
  without supporting evidence.
- Explain that bulk salvage-agent agreements may not be available to the claimant.
- Keep the reasoning tied to vehicle value, repair cost, damage severity, category, and available
  salvage evidence.
- Use firm/final wording only where the category and salvage evidence are complete enough.

## Avoid

- "It is Cat S because repair cost is high."
- "It is Cat N because there is no visible chassis damage" where the vehicle has not been stripped
  or inspected sufficiently.
- "ABI says..." without verifying the current source wording where exact Code language matters.
- Overconfident category language in Cat A/B, HV, water, fire, or motorcycle cases.

## Handoff

After the category reasoning is set, draft the email or letter through `ce-house-style`.
