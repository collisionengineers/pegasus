# Windows desktop workstation

The very-long-term direction is a Windows-installed, case-centred composition of accepted Pegasus
capabilities. It may eventually provide local integration and an offline/degraded experience, but
it must not duplicate `Pegasus.Core` policy, the root `design/` UI contract, application state,
document rendering, audit identity, or connector ownership.

No desktop runtime is implemented or activated here. Framework selection and implementation require
a root product allocation, accepted architecture decision, exercised caller, design mapping, and
installation/update/security evidence. See the
[desktop application direction](../../docs/architecture/desktop-application-direction.md).
