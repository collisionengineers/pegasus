# Models

This folder stores versionable model-family definitions, licences, model cards, inference contracts,
promotion manifests, and small configuration files.

Weights, checkpoints, adapters, and exported binaries may be versioned here when repository size and
licensing make that practical; otherwise place them in the chosen artifact registry and reference
them by immutable hash. Run output and caches should remain separate from promoted artifacts. No model
is currently approved for production.
