# Documentation

- `architecture/` — current system and trust-boundary descriptions.
- `adr/` — durable architecture decisions and proposals.
- `governance/` — data, privacy, security, model, and release controls.

Long-term product direction is recorded in
[architecture/desktop-application-direction.md](architecture/desktop-application-direction.md).

Current data-use authority is recorded in
[governance/data-authorisation.md](governance/data-authorisation.md).
Local AI Centre corpus use is defined in
[governance/development-mlops-corpus.md](governance/development-mlops-corpus.md).

Status claims must say whether a capability is implemented, locally verified, proposed, or blocked.
