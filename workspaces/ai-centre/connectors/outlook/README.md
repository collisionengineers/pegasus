# Outlook connector

Planned delegated connector for scoped mailbox search, thread reading, attachment import, and draft
creation. Sending must remain a distinct operation that requires the user to review and approve the
exact recipients, subject, body, and attachments.

Before implementation, record tenant ownership, mailbox types, delegated scopes, retention, audit,
shared-mailbox behaviour, and the local mock contract. No real mailbox is authorised by this scaffold.
