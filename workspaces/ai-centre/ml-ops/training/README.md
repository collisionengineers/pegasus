# Training

Reproducible, configuration-driven training entry points belong here. A run must pin the base model
and licence, dataset manifest/hash, code revision, environment, seeds, hyperparameters, hardware,
cost, outputs, and evaluation suite. Approved bounded inputs may be read from the ignored
`corpus/ai-centre/` boundary; neither those inputs nor complete Box/Outlook archives may be
committed to Git.
Starting a concrete local or hosted run remains an explicit implementation task; billed runs also
require the documented account, region/SKU, corpus size, and spending cap.
