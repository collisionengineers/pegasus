# Optional brief overlay — cloud / infrastructure

Copy this prompt set into the brief when the ticket changes cloud resources, deployment, or infrastructure.

- **Target:** state tenant, subscription, account, project, region, and environment as applicable.
- **Identity:** name the least-privilege identity and permissions required for the operation.
- **IaC diff:** identify the infrastructure definition and the expected resource-level change.
- **Plan evidence:** capture plan, dry-run, or equivalent output before applying a change.
- **Cost and rollback:** state the expected cost effect and the concrete rollback path.
- **Secrets:** keep credentials, tokens, and secret values out of the brief, code, logs, and proof.
