# Pegasus Case-workspace local instructions

In addition to the parent Web UI instructions, read and follow:

- `../../../../.agents/skills/pegasus-ui-guardrails/references/case-workspace.md`

The Case v26 frame and section ownership are frozen by default. Adding or fixing a Case feature does
not authorize moving sections, duplicating evidence, adding a second action route, changing the
ribbon/section-row model, or replacing read/edit geometry.

Only an explicit current operator instruction to change the Case design/layout authorizes those
changes; durable changes must update the owning design/FRD contract.
