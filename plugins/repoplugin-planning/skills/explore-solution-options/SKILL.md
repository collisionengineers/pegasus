# Explore Solution Options

Read the brief and persisted research. Write a concise options record with viable choices, rejected alternatives, trade-offs, reversibility, risk, and the fact that would change the recommendation. Record a blind-spot pass and a pre-mortem where they can uncover unknown unknowns.

Use a prototype only for a named uncertainty, with a small exit criterion and disposal rule. Do not invent policy, add speculative layers, write the implementation plan, or resolve user-only contradictions. Send material uncertainty to `open-questions.md` through the planning lead.
