# Optional brief overlay — docs

Copy this prompt set into the brief when the ticket changes documentation.

- **Audience:** identify who needs this information and the decision or task it supports.
- **Source of truth:** name the governing code, product document, or measured behaviour the text must reflect.
- **Claims changed:** list the user-visible claims being added, corrected, or removed.
- **Examples executed:** run each command, snippet, or workflow example against the intended version before claiming it works.
- **Version sensitivity:** say whether the guidance is version-specific and how readers can tell when it is stale.
