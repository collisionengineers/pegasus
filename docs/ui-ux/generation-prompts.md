# Mockup generation prompts

All three used the built-in image generation tool in `ui-mockup` mode. The supplied intake dashboard screenshot was a structural/style reference, not an edit target.

## Concept 1

High-fidelity 16:9 operations cockpit for a small Collision Engineers office: charcoal left navigation, white header, queue cards for Not ready, Review, Held; inbox cards for Receiving work, Queries, Other, Needs sorting; operational lists for Due today, Chasers due (7 days), Cleared this week, and Recent activity. Warm off-white, white panels, charcoal, near-black, CE red accents, amber and navy state accents, system sans, 2px corners, border-first, restrained shadows, Lucide-style icons. No gradients, glass, decoration, `Triage`, Azure/cloud/AI/developer language, or watermark.

## Concept 2

High-fidelity 16:9 split-pane intake sorting workspace: left incoming list and All/Instructions/Images filters; wide centre email/document/attachment/evidence preview; right Create case candidate form with Principal, Registration, Work type, Due by, Instruction complete, Images complete, Hold, and Create for review. Suggestions must be distinct from confirmed values. Use CE-derived internal-app palette and restrained information density. No gradients, decorative charts, `Triage`, implementation language, or watermark.

## Concept 3

High-fidelity 16:9 case workspace for `QDOS26001`: charcoal navigation; header with registration, principal, work type, due date, Review, assigned engineer and Reopened; tabs Overview, Documents, Images, Report, Audit trail; instruction summary, completeness, next action, Box folder; right timeline, seven-day Chaser due with Copy message, case controls; Related work includes `a.QDOS26001`. No delete action, gradients, decorative charts, implementation language, or watermark.
