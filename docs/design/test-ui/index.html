Pegasus Test UI

Visual routes

  • /Account/AccessDenied
    • default — Access-denied page.
  • /Account/PasswordChange
    • default — Ordinary voluntary password-change form.
  • /Account/SignIn
    • default — Unsigned-in form without signed-out or validation notice.
    • validation — ModelState is invalid and the sign-in form is redisplayed.
    • signed-out — Model.SignedOut is true.
  • /Administration/Accounts/Confirm/{operation}/{staffId:guid}
    • disable — The explicit disable account action confirmation.
    • enable — The explicit enable account action confirmation.
    • delete — The explicit delete account action confirmation.
    • force-logout — The explicit force-logout account action confirmation.
    • reset-password — The explicit reset-password account action confirmation.
    • clear-lease — The explicit clear held case edit confirmation.
  • /Administration/Accounts
    • default — Populated account table and create form.
    • empty — Model.Accounts.Count is zero.
  • /Administration/Automation/Activity
    • default — Unfiltered activity page with no records.
  • /Administration/Automation
    • default — Composed and enabled automation controls.
  • /Administration/Configuration
    • default — Loaded default case-workflow policy configuration.
  • /Administration/ClaimSources
    • empty — No claim sources and the create form is available.
  • /Administration/ClaimSources/Edit/{id:guid}
    • default — Loaded active claim source before its first edit.
  • /Administration
    • default — Administration landing on the admin-layout: area rail and area cards, Automation absent when not composed.
  • /Administration/Mailboxes
    • default — One approved identity-bound mailbox before its first poll.
  • /Administration/Organizations/Edit/{id:guid}
    • default — Loaded Work Provider organization with one active principal.
  • /Administration/Organizations
    • default — No organizations plus create form.
  • /Administration/Principals/Create
    • default — Loaded organization and available work-provider create form.
  • /Administration/Principals/EvaSubmission/{organizationId:guid}/{principalId:guid}
    • default — Loaded organization and principal with the EVA API submission settings form.
  • /Administration/Principals
    • default — No organizations branch.
  • /Administration/Principals/Replace/{organizationId:guid}/{principalId:guid}
    • default — Loaded active predecessor and available replacement form.
  • /Administration/Roles
    • default — Populated account role-assignment table and form.
  • /Administration/ValuationPresets
    • default — Seeded valuation presets with amount, enabled state, version and administrator edit/create controls.
  • /Cases/Create
    • default — Allowed case creation with editable instruction draft.
  • /Cases/{id:guid}
    • default — Case record: the single-scroll workspace in Review with the edit lease held (header, sticky identity ribbon, action bar, edit bar, section jump-nav, eleven section hosts, context column).
    • unavailable — The case query failed and the workspace renders the unavailable notice.
    • conflict — The submitted expected version is stale and the non-destructive conflict notice is rendered.
  • /Cases/{caseId:guid}/Eva/Send
    • default — A Review case with manual submission enabled, choosing between the API submission and the export.
  • /Cases
    • default — Triage tab with populated results.
    • empty — The selected tab query succeeds and its result collection is empty.
  • /authorize
    • default — Valid connector authorization request.
  • /Error
    • default — Retryable error with return path and support reference.
  • /VehicleImages/{id:guid}
    • default — Awaiting-instruction image case with no registered images.
  • /
    • default — Current loaded dashboard with ordinary metrics.
  • /Received/{id:guid}
    • default — Blocked-intake receipt with source evidence and held lease.
  • /Inbox
    • default — Populated Inbox folder.
    • empty — The current mail query succeeds and returns no rows.
    • unavailable — The current mail query is unavailable and no false empty result is rendered.
  • /Inbox/Compose
    • default — Initial new-message form before validation or submission.
  • /Inbox/{id:guid}
    • default — Message active section with correction dialog closed.
  • /Operations
    • default — Populated ordinary operations work without AI limit.
    • empty — External work and upload-link collections are both empty.
    • partial data — Administrator view when a service health row is partial or failed.
  • /Search
    • default — Successful populated case results.
    • empty — The case query succeeds and Model.Results.Count is zero.
    • unavailable — The case query is unavailable and no false empty result is rendered.
  • /status/{code:int}
    • default — 404 status with dashboard return enabled.
  • /Triage/{id:guid}
    • default — Open assigned Triage item with evidence candidates.
  • /Unidentified/{id:guid}
    • default — Open item with retained source receipt.
  • /Upload
    • default — Initial internal upload form.
    • validation — ModelState is invalid and the upload form is redisplayed.
  • /Upload/Group/{id:guid}
    • default — Completed grouped upload outcomes.
    • processing — At least one group member has no completed outcome and refresh remains available.
    • needs-decision — A completed grouped upload requires a staff decision.
  • /Uploads/{token}
    • default — Valid external upload policy and initial form.
    • validation — ModelState is invalid under a valid upload policy.
  • /Upload/Status/{id:guid}
    • default — Completed case-created upload outcome.
    • processing — Model.Outcome is null while processing is incomplete.
    • needs-decision — The completed upload requires a staff decision.
  • /Administration/Health
    • default — Authorized administration query view.
  • /Administration/ActionLogs
    • default — Authorized administration query view.
  • /Administration/AiJobs
    • default — Authorized administration query view.
  • /Administration/Reports
    • default — Authorized administration query view.
