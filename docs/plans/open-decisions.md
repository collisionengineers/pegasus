# Open decisions

These questions are deliberately not resolved by the scaffold:

- Exact permission matrix for every lifecycle transition.
- Whether and how a principal/year sequence may be reassigned after allocation.
- The interim state and identity rules for a standalone audit before the engineer's repairable/total-loss finding.
- Principal-specific required intake fields and completeness rules.
- Exact boundary between `Review` and `Held` queues.
- Whether DVLA/DVSA enrichment, capture UI, Maps/Vision, or existing Foundry evaluations belong in the first production cutover.
- The benchmark result and final library choice for embedded PDF text extraction.

Resolve these from operator decisions and genuine examples before making them irreversible in schema or workflow code.
