
Collision Engineers receive different types of cases, that have different processes attached to them. This will outline the definitions and processes.

This primarily affects how the Case/PO number is handled. See: operator-notes/collision-engineers-process/case-guide/case-po-definition  for more information.

1. Inspection
2. Audit
3. Audit + Inspection
4. Diminution
5. Commercial 

**Inspection**

This is our standard case type, with no special or particularly noteworthy features.

We receive instructions, and prepare the case to be passed to an Engineer for inspection. Then, the engineer prepares a report and sends this back to the provider.

**Audit**

In this case type, an inspection has already been carried out, but by a different firm of Engineers. Here, we receive instructions, as well as a copy of their original report.

This functions similarly to an inspection, but the Engineer is essentially "auditing" the other firms report - akin to double checking their work.

**Audit + Inspection**

In this situation, we are being asked to perform an initial inspection by the same process as a standard inspection.

After this, we are carrying out an Audit on that same inspection.

**Diminution**

Deferred at this time. This is included for provenance but the cases are not frequent enough to make it into a first build.

**Commercial**

This is currently the same situation as Diminution. This is included for provenance but the cases are not frequent enough to make it into a first build.
