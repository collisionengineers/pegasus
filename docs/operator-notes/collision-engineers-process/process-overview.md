
This document outlines a broad brief overview of the lifecycle of a case for Collision Engineers.


**Stage 0 - Triage**

This doesn't count as a case technically, but the e-mails should be stored. A work provider sends a request asking us to assess whether a vehicle is roadworthy or unroadworthy.

This stage does not always occur, and it may not progress into a full case. It may be followed by receiving instructions for that vehicle however.

**Stage 1 - Receiving Instructions / Images**

Related documents: operator-notes/collision-engineers-process/initial-case-intake

We receive initial instructions from a provider, or images from a repairer, and prepare the case to be passed to an Engineer.

**Stage 1.5 - Chasing for details/images/documents**

If the case is incomplete, we chase up the relevant party for the required information. When this is obtained the case can proceed to the next stage.

**Stage 2 - Inspection**

An Engineer carries out a desktop inspection, and prepares a report that details the vehicles roadworthiness, along deeming it either repairable, or a total-loss. It also contains an estimate for the repair cost.

**Stage 3 - Post-Report**

The Engineer has sent the report back to the provider at this stage. The provider, or the third party insurance, or the claimant, may have queries/disputes about the report that are generally received via e-mail. The Engineer would then need to respond to these.
