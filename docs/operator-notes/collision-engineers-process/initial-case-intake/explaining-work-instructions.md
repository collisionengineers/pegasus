
This document outlines what a work instruction is, and what it contains.

This is a document containing details of a Claimant that has been involved in a road traffic accident. The document will contain various details that must be extracted and captured such as:

Work Provider (also referred to as a principal)
Claimant Name
Claim Number (an external reference number)
Vehicle Registration (VRM)
Vehicle Make
Vehicle Model
Vehicle Mileage
Accident Circumstances
Date of Incident
Instruction Date (if this is not on the document, it defaults to the current date)
Inspection Address (see: operator-notes/collision-engineers-process/inspection-address)

It is also a requirement to have a set of vehicle images. These must ideally show the damage the vehicle has sustained, as well as a clear view of the registration.
