
# cedocumentmapper

This is a Python extractor with a Tkinter UI made by a previous developer at Collision Engineers.

The project will not use this implementation as it is very poorly designed and made.

Pegasus uses PdfPig as the authoritative embedded-PDF extraction method. The
legacy `cedocumentmapper` implementation is not used; a bespoke extractor remains
deferred until its hardening is separately accepted.
