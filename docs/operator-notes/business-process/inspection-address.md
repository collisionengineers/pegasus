# Inspection address

Collision Engineers does **not** physically inspect vehicles. All assessments are carried out via desktop inspection.

Despite this, there are two options for an inspection address.

1. The location of the vehicle—either the client's address or the location of the garage/repairer.
2. No address. We put "Image Based Assessment" instead.

Some providers are set to **always** be put down as an image based assessment, but in many cases we will need the address the vehicle is physically being inspected at. This is for the report itself, and is important to get.

At present, this is not handled ideally. It mostly relies on Admin staff who
just "know". Some instruction documents state where the vehicle is. When they
do not, it is usually one person who can tell from the images or knows which
repairer that provider generally uses.
