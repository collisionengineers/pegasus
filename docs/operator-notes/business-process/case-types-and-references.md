# Case types and internal references

## Case/PO number

A Case/PO number is Collision Engineers' internal reference system. It is a
simple system that is uniform across all providers.

## Case types

Collision Engineers receives different case types with different processes.
The case type primarily affects how the Case/PO number is handled.

### Inspection

This is the standard case type, with no special or particularly noteworthy
features. Collision Engineers receives instructions and prepares the case for
an Engineer to inspect. The Engineer prepares a report and sends it back to the
provider.

### Audit

An inspection has already been carried out by a different engineering firm.
Collision Engineers receives instructions and a copy of the original report.
The process is similar to an inspection, but the Engineer audits the other
firm's report—akin to double-checking its work.

### Audit + Inspection

Collision Engineers first performs an inspection using the standard inspection
process, then carries out an Audit on that same inspection.

### Diminution

Deferred at this time. This case type is retained for provenance, but cases are
not frequent enough to include in a first build.

### Commercial

Currently the same situation as Diminution. This case type is retained for
provenance, but cases are not frequent enough to include in a first build.
