# Icons

Lucide is the approved web/UI icon system inherited from the provided design
foundation: 24×24 viewBox, 2px stroke, round caps/joins, 16–24px rendered size,
and `currentColor`. No emoji, Unicode dingbats, hand-drawn icons, or
infrastructure symbols.

No Lucide package/source is currently exercised in the application, so
onboarding adds no dependency or copied SVG set. `src/CollisionSpike.Web/wwwroot/favicon.ico`
is a browser asset with unrecorded provenance, not icon-system authority. A
future selected UI change must choose a repository-owned delivery path, map each
used glyph, and provide accessibility labels where the icon is not decorative.
