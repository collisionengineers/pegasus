# Icons

No approved icon set or source icon assets are tracked. The current UI uses
textual marks/characters and `src/CollisionSpike.Web/wwwroot/favicon.ico`; the
favicon's design provenance is not recorded and it is not authority for an icon
system.

Do not generate placeholders, extract screenshot icons, or use infrastructure
symbols as user concepts. A future icon addition requires an approved source
and exact runtime mapping.
