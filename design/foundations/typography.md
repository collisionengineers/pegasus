# Typography

## Type roles and hierarchy

The current proof uses operational system-sans body text, compact uppercase
section labels, strong queue/metric values, and a clear page-heading hierarchy.
Planned body text remains 14–16px with semantic heading structure.

## Font sources

System stack only: `"Segoe UI", Arial, sans-serif`, as exercised in
`src/CollisionSpike.Web/wwwroot/css/site.css`.

## Runtime consumers

All current Razor Pages use `src/CollisionSpike.Web/wwwroot/css/site.css`. No
bundled or downloadable font is approved.
