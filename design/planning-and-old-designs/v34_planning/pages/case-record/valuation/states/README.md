# Valuation: states

The eleven presets in the mockup strip, each reachable as `?state=<id>`:

| Id | State |
| --- | --- |
| `fetched` | Editing: Glass's fetched, the other guides typed, CAP chosen, nothing recorded |
| `fetched-read` | Reading the same |
| `recorded` | Editing: a calculation recorded against CAP, with an earlier AI market research |
| `recorded-read` | Reading the same |
| `own` | Editing: the Engineer's own figure typed over the calculation |
| `refused` | Editing: deductions exceed the value; Core's sentence, box back to the saved figure |
| `claimant-vat` | Editing: claimant is VAT registered; the VAT row is disabled with its tag |
| `pending` | Editing: AI market research in progress |
| `inspection` | Editing in the Inspection view: no research month or research Get valuation |
| `empty` | Editing: nothing recorded; "None yet" |
| `empty-read` | Reading: nothing recorded |
