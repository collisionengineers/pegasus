# Tasks: panels

1. **New task** (`data-case-task-form`): one required text box and **Add task**. Edit session only.
2. **The table** (`data-case-tasks`): Task, Assignee, State and, in the edit session, an unlabelled actions column. An open row's actions are the Assign form (`data-case-task-assign`: a select and **Assign**), **Complete** and **Cancel task**.
