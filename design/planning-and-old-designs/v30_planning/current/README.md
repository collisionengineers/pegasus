# v30 current: five surfaces, polished

**Temporary design review artifact.** Created at the operator's request on
24 September 2026 (the Upload flow, five alternatives) and widened on
25 September 2026 to the sign-in frame, the Inbox, the Work Centre and
Administration → Staff accounts. It is not application code, not design
authority and not implementation evidence. The final Stage 2 PR keeps or
removes this folder as the operator instructs.

## What it is

Every file is self-contained and offline: the live `site.css`, the page
stylesheets, Inter and the two refined Pegasus marks are inlined, and the
shell is rebuilt from `_Layout.cshtml` at `origin/dev` `32dabfc59`
(25 September 2026), so it carries no working-set strip and composes the one
Refresh partial. Nothing reads or writes Pegasus data; every figure, name
and reference is a synthetic fixture.

Each surface pre-renders every **state** in two **layers**:

- **Baseline** — the live page's markup and classes, read from the Razor
  source, with the fixture in it. It is the thing to compare against.
- **Proposal** — the same page with this round's lettered items layered
  over it. Undecided choices are **switches** in the strip (`opt=`).

## How to open it

Open [pegasus_v30_walkthrough.html](pegasus_v30_walkthrough.html) straight
from the file system. The dark bar at the top is demo control, not product
UI: pick an area, a state, Proposal or Baseline, any switch, and a width
(Fit, 1580, 1440, 760). **Open alone** opens the surface file itself, whose
**Mockup controls** strip at the bottom left holds the same controls.
