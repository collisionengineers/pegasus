# Inbox: states

| State | Query | Shows |
| --- | --- | --- |
| Default | `?state=default` | Three panes: scopes, messages with a selected row, the preview |
| List | `?state=list` | Two panes: no selection, no preview |
| Empty | `?state=empty` | "No mail has been received." |
| Stale | `?state=stale` | Freshness **Stale** chip beside the last-good time |
| Dismissed | `?state=dismissed` | The Dismissed scope with Restore buttons and no Folder select |
| Deleted | `?state=deleted` | Deleted Items search: the truncation notice and read-only rows |
| Search | `?state=search` | A search term with "Matched in:" lines |
