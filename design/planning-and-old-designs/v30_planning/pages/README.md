# v30 planning: pages

One folder per live page this round touches. The round polishes five
surfaces without changing what they do: the sign-in frame, the Inbox, the
Work Centre, Administration → Staff accounts (the list and the settings
dialog) and the Upload flow, whose five layout alternatives were the first
pass of this round (24 September 2026).

Each `how-it-works.md` is read from the live source (`origin/dev`
`32dabfc59`, 25 September 2026) and describes the page as it is today, so
the proposals can be compared against it. Each `how-it-should-work.md`
waits for the v30 sign-off. A page reached from another page is a
subfolder of it.
