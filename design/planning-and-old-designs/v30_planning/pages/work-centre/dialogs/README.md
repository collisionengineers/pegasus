# Work Centre: dialogs

| Dialog | Opened by | Mockup |
| --- | --- | --- |
| Assign Engineer (`wc-assign-dialog`) | **Assign Engineer** in the Today pane on an Unassigned item | `?state=assign` |

## Three-design pass

All A/B/C previews include a working Assign Engineer dialog: required
selection, Assign to me, Cancel, Assign, focus containment, Escape and
focus return. `?state=conflict` opens the refusal state and leaves the
fixture unassigned.

C additionally uses a Selected work drawer. A row opens its own facts and
actions; closing returns focus to the row. Links outside the Work Centre
open a clearly labelled mockup destination boundary.

See the [proposals](../../../current/work-centre-design-proposals.md).
