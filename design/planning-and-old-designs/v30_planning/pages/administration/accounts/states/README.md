# Staff accounts: states

| State | Query | Shows |
| --- | --- | --- |
| List | `?state=list` | Four accounts, the admin nav, Create staff account |
| Settings, own account | `?state=settings-self` | The `alex` dialog (the operator's 25 September screenshot in the baseline layer) |
| Settings, another account | `?state=settings-other` | An enabled Engineer with Disable, Force logout, Reset password and Delete |
| Settings, disabled account | `?state=settings-disabled` | A disabled User: Enable and Delete only |
| Error | `?state=error` | The settings dialog with "Enter the printed name for the Sign-off Engineer." |
| Create | `?state=create` | The Create staff account dialog |
| Temporary password | `?state=temporary-password` | The once-revealed temporary password after Reset password |
| Delete | `?state=delete` | The native Delete confirmation over the settings dialog |
