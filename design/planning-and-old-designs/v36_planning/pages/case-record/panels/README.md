# Case record panels

Temporary review artifact; see the [page README](../README.md).

Sections in order, each a foldable panel with a 51px head: Case details, Claim, Original report (Audit Cases), Inspection details, Vehicle (Damage and Valuation nested), Repair Spec, Decisions, Report, Files, Notes. The aside holds Views (once an Audit exists), Linked cases (while a Triage is linked), Figures, Next action and Report not ready.

The findings table in the [notes](../../../current/v36-notes.md) is grouped by these panels; the mockup's strip lists the same groups.
