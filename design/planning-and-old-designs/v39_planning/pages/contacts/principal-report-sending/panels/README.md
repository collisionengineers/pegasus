# Report sending panel: panels

The panel follows Report generation on an active Principal's Contact page. In order:

1. **Send from**: a select of the Approved mailboxes, with "Not set".
2. **Send to**, **Cc**, **Never cc**: repeated e-mail inputs, each with **Add address**; Send to carries the hint "Empty: the original instruction sender."
3. **Send to only**, **Reply all**, **Garage figures**: ticks.
4. **Attach**: six ticks: Fee note is a separate PDF, Estimate, Audatex, Report carries vehicle images, Vehicle images document required, Figure breakdown required.
5. **Hold**: text, with the hint "Send stays off until staff tick this as done."
6. **Reminders**: repeated text inputs with **Add reminder**.
7. **Attachment name**: First send and Re-send, with the hint "Use {ref}, {reg} and {outcome}. Empty: the standard name."
8. **Rules**: one fieldset per rule (legend "Rule"): Match (All conditions / Any condition); at least three condition lines, each a kind select and the value field that kind reads (a Contact list, the outcomes, or text with the hint "Separate several with commas."); Cc add, Cc remove, Remind, Hold, Stop (hint "Send is refused; staff may override with a reason."); **Remove rule**. One spare blank rule row, then **Add rule**.
9. **Save report sending**.
