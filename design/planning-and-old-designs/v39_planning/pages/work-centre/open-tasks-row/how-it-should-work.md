# Work Centre Open tasks row: how it should work

Decided with the operator on 6 October 2026. The rules below are what the source now does under those rulings; the round awaits design sign-off.

- **D1.** A Case with at least one open task is one Needs attention row, named by its oldest open task and "(+N more)" when it has others.
- **D2.** The row has no due instant, so it always sits under Later.
- **D3.** Owner is the oldest open task's assignee, else the staff member who created it, else "Unassigned"; the row is on Mine for its owner only.
- **D4.** The row's action opens the Case at its Tasks section.
- **D5.** A dismissed row returns once a newer open task is created on the Case.
- **D6.** The Tasks chip filters the kind like the other kind chips and counts over the whole scope.

Open: which open task is "first" (the oldest by creation today).

Open: what the Received column shows (the first task's creation today).

Open: the chip's position (before AI draft today).

Open: the kind label "Open tasks", the chip "Tasks" and the action "Open tasks", plain labels chosen for building.
