# Next action after the send, and the ribbon gates: how it should work

Decided with the operator on 6 October 2026. The rules below are what the source now does under those rulings; the round awaits design sign-off.

- **D1.** Once Report sent is recorded, the Next action lists the Case's open tasks, oldest first, in the report-blocker style under the heading "Tasks", each row linking to the Tasks section.
- **D2.** While the Case has an open task, the Next action's Mark completed step is a greyed button whose hover text is "Complete or cancel every open task first."
- **D3.** While the Case has an open task, the Actions menu still lists Mark completed and Archive, greyed with the same hover text, as Create audit is when refused.
- **D4.** The store refuses to complete, close or archive a Case with an open task, with the same sentence, whatever the page shows.
- **D5.** On an Inspection + Audit Case with no Audit yet, the step after the send stays Create audit, and the open tasks are listed under it.

Open: how the gate shows in the Cases rail quick detail: "Current work" is a text pair today and does not carry the reason.

Open: one "Tasks" button per listed task, against one link for the whole list.

Open: whether the open tasks are listed in the Inspection view as well as the Audit view of an Inspection + Audit Case (both today).
