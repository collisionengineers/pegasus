# Case record — states

The states the baseline can show, each a strip row and a query preset (`../../../current/v27-notes.md` § 9):

- Lifecycle: Not ready (03), Review (04), With Engineer (01), With Engineer · post report, Held (05), Completed (06, 07), Query, Closed · Provider cancelled (08), Closed · Created in error (62)
- Edit lease: reading, editing (02), a colleague editing (09)
- Role: Engineer, Administrator (53), User (52)
- Layout: Scroll, Tabs (37); rail expanded or collapsed (38)
- Data: present, every list empty (36), a stale save refused (60), the Case unavailable (61)
- Case type: Inspection, Inspection + Audit (39), Audit (40); archived
- Glass's session: none, Open (20), Waiting (21), Failed, held from another Case (22)
- Decisions: an AI proposal on the Settlement strip (25)
- Report: not generated (29), generated (26), stale (28), delivery prepared
- AI draft ready on Next action (41)
- Custody: confirmed, preparing (33, 64), unavailable
- Vehicle lookup: looked up, not yet looked up, failed (13)
- EVA policy: ZIP, manual API, API not enabled (63), automatic delivery failed
- Design variable — Damage selector: live panels, A · Pins (66, 70), B · Brush (67), C · Areas (68), D · Impact arrows (69, 71); every variant records the eight areas
- Design variable — Logo: refined mark (72, 73), live lockup (74)
- Design variables — Proposals (nineteen switches, `v27-notes.md` § 15): all on (75–89) or all off (every baseline shot); fixture switch Repairer: Bootle or Croydon (79)

One subfolder per state as planning for it starts.
