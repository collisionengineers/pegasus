# Logos

## Approved sources

No approved logo image is tracked as a runtime design source. The current
`.brand-mark` renders the letters `CE` in CSS/HTML and must not be represented as
the approved Collision Engineers logo.

## Rules

Do not invent, redraw, extract from a screenshot, or copy a generated logo into
this directory. A future selected UI implementation must add the exact approved
source, source-to-runtime mapping, and usage rules through reviewed design work.
