# Design tokens

- Canonical token source: `src/CollisionSpike.Web/wwwroot/css/site.css`
- Format/generator: CSS custom properties; no generator
- Generated/runtime outputs: none; the canonical source is consumed directly

## Token groups

The exercised shared group is colour: `--ink`, `--muted`, `--paper`, `--panel`,
`--line`, `--navy`, `--amber`, and `--red`. Typography, spacing, radii, and
motion are not formal shared token groups. Add one only when multiple exercised
consumers require it; never duplicate or hand-generate outputs.
